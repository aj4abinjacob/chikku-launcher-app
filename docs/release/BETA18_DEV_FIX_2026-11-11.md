# Beta 18 (build 19) — dragged widgets no longer stay faded, 11 November 2026

submitted to the existing Closed testing – Alpha audience. Production remains NO-GO.

  kept after the drop; it is now reset to opaque on every bind. A held widget's old cell dims to 75%
  instead of the icon dim of 30%, so it stays readable on a light wallpaper. One cherry-pick with a
  trivial conflict (two adjacent constants, both kept). No settings, backup, permission, dependency or
